Antes de comercializar

Pendiente
  • Multiempresa: el selector separa datos de demostración dentro del navegador, pero no es aislamiento real de datos.
  • DGII / e-CF: el recibo actual es interno y no es un comprobante fiscal electrónico válido.
  • Pagos: no se procesan tarjetas; el método se registra manualmente.
  • Seguridad: no hay inicio de sesión, roles efectivos, cifrado de servidor ni copias de seguridad remotas.
  • Inventario: el control actual es manual; recetas y descuento automático de ingredientes están pendientes.
  • Producción: para operar comercialmente se requiere backend, base de datos, pruebas, monitoreo y soporte.
